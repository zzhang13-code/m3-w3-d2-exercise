# Week 3 Day 2 Sass exercise

Completed from the instructor's `m3-w3-d2-demo` starter ZIP. The four original HTML pages are retained, with CSS links added to demos 1 and 2. Each Sass example follows its corresponding starter file: variables, nesting, mixin, and import.

Run `npm install` and `npm run scss` to compile the SCSS files, then open `sass-demo1.html` through `sass-demo4.html` in a browser. This project uses the maintained `sass` compiler because the starter package's `node-sass` 4.14.1 does not support current Node versions.
